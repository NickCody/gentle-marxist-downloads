# Download The Gentle Marxist

A desktop app for exploring Marxist ideas, political history, and political economy through conversation and source readings.

| Your computer | Download | Install |
| --- | --- | --- |
| **Windows 10/11, x64** | **[Download the Windows installer (.exe)](https://github.com/NickCody/gentle-marxist-downloads/releases/latest/download/Gentle-Marxist-Windows-x64-Setup.exe)** | Run the downloaded file and follow the setup wizard. Then open The Gentle Marxist from the Start menu. |
| **Mac, Apple Silicon or Intel** | **[Download the Mac disk image (.dmg)](https://github.com/NickCody/gentle-marxist-downloads/releases/latest/download/Gentle-Marxist-macOS-universal.dmg)** | Open the DMG. Drag **The Gentle Marxist** onto **Applications**, then launch it from Applications. |

You do not need Node, Rust, or developer tools. Choose the `.exe` or `.dmg` above; GitHub's source-code ZIP/TAR downloads are not installers.

## First launch

Open **Settings → Models** and connect a supported local model or model provider. The installer does not include an AI model. The app includes Chat and a Library of source readings.

These early installers are not notarized or signed with a distribution certificate. macOS Gatekeeper or Windows SmartScreen may require approval before the app can run.
