You do not need Node, Rust, or developer tools. Choose the `.exe` or `.dmg` above; GitHub's source-code ZIP/TAR downloads are not installers, and the .app.tar.gz and latest.json files are for the app's own updates.

The Windows installer is unsigned. Windows SmartScreen may show a warning when opening it. The Mac app is ad-hoc signed and is not notarized by Apple. Only approve an installer you downloaded from this page and trust.

## Install on Windows

1. Download **Immortal-Marx-Windows-x64-Setup.exe** using the Windows link above.
2. Open the downloaded file. If **Windows protected your PC** appears, click **More info**, then **Run anyway**.
3. Follow the setup wizard, then open **Immortal Marx** from the Start menu.

If **Microsoft Edge** warns that the file is not commonly downloaded, open its Downloads list, click **…** beside the file, then **Keep → Show more → Keep anyway**. [Microsoft's download-warning help](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-security-smartscreen).

If **Run anyway** is missing, Smart App Control or your organization's policy may block the installer. These steps cannot override that restriction. [Microsoft's SmartScreen guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Install on Mac

1. Download and open **Immortal-Marx-macOS-Apple-Silicon.dmg** using the Mac link above. It needs a Mac with Apple Silicon (M1 or later); Intel Macs are not supported.
2. Drag **Immortal Marx** onto **Applications** in the disk-image window.
3. Open **Immortal Marx** from **Applications**. If macOS says the developer cannot be verified or Apple cannot check the app, dismiss the warning without moving the app to Trash.
4. Open **System Settings → Privacy & Security**, scroll to **Security**, and click **Open Anyway** for Immortal Marx. Confirm **Open** and authenticate if asked. You can then launch the app normally.

If **Open Anyway** is missing, try opening the app from Applications once more, then return to Privacy & Security. A managed Mac may require your administrator's help. [Apple's instructions](https://support.apple.com/en-us/102445).

These steps apply to unknown or unverified-app warnings. If a warning reports malware or a damaged file, stop instead of approving it. Leave your computer's security protections enabled.
